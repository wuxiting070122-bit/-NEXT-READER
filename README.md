# 下一位读者 · BOOKLOOP

从图书馆管理课程项目延伸的原文阅读与共读平台。现有页面保留棕色复古桌面风格，以“阅读原文 → 针对段落提问 → 有依据地回应 → 帮助下一位读者”为核心。

## 运行

推荐 Node.js 22+。执行 `npm ci`、`npm start`，访问 http://localhost:3000/research.html 。SQLite 默认使用 `lib.db`；`LIBRARY_DB` 可指定独立数据库，`PORT` 可指定端口。服务仍仅监听 `127.0.0.1`，尚未部署公网。

数据库启动时只补充缺失的表、字段和内置资源，不覆盖用户内容。本次升级前的数据库备份为 `backups/pre-community.db`。不要在服务运行时替换数据库文件。

## 已实现

- 注册、登录、退出；随机盐 + scrypt 密码哈希；会话 Cookie HttpOnly / SameSite=Lax。账号与借阅、批注、阅读位置、阅读前后记录绑定。
- 管理员编辑资源、下架/重新上架、设置开放或限额借阅。下架保留历史，仍可归还；正文修改产生新版本，旧批注和讨论保留原选段，不自动附着到新文字。
- 开放电子书支持多人同时加入书架；文章和链接可直接阅读。限额电子书采用席位数和期限（默认 14 天），支持预约、归还、无预约时续借一次。预约按先后领取；预约者可取消。预约暂不设置自动失效期限。
- 限额借阅到期后，在下一次 API 请求时自动归还并生成站内通知。没有独立后台定时任务，不发送邮件提醒。
- 标题、作者、标签和正文搜索；管理员可以粘贴纯文本正文，用空行分段、`## 章节标题` 分章（上限 300,000 字符）。目录导航、账号阅读位置自动保存与恢复、手动保存阅读位置、笔记编辑和 JSON 导出。不是 EPUB/PDF 解析器；三本文学书仍是节选。
- 私人批注默认私密。公开发布需独立确认；四种讨论类型：提问、解释、译法讨论、个人感想。回复至少提供来源链接或原文依据位置；不自动认证依据正确。
- 讨论发起者可标记待解答、已解答、仍有争议；读者可标记回复“对我有帮助”，撤回自己的内容、举报他人内容。管理员可核查并隐藏举报内容。
- 回复通知、预约席位释放通知、到期通知；个人消息已读状态按账号隔离。“共读互助”展示真实公开讨论；统计面板记录回复和帮助反馈，不虚构学习或环保效果。
- 材料再利用主题馆：EPA 真实来源短引文 + 两篇明确标注的原创英文练习；私密阅读前后记录与下一步行动。原始来源 https://www.epa.gov/recycle/what-you-can-do （2026-10-04 核对）。练习为 AI 辅助编写，不冒充专业原作或维修指南。

## 管理员

新注册账号默认均为普通读者，不存在“第一个注册者自动成为管理员”。先在网页注册自己的账号，再由本机项目操作者执行：

```sh
node scripts/set-admin.js 你的账号名
```

使用其他数据库时，该命令也需设置相同的 `LIBRARY_DB`。刷新页面后，页脚出现“资源管理”，其中包含馆藏编辑和“举报处理与使用统计”。不内置正式环境的默认管理员密码。

旧版 `/demo.htm` 的 13 个课程接口仍保留，旧版读者证与新版账号尚未合并。旧 `/init`、`/seed`、图书/读者/借还接口及 `/api/research/*` 现在都必须通过管理员权限。旧版搜索页面为 `/research-legacy.html`，不再作为普通读者页面。

`/init` 和 `/seed` 会重置旧课程表，不能用来重置新的账号或数字共读数据。迁移前没有账号归属的旧借阅、批注不自动分配给任何人；后续可在确认身份后人工迁移。

## 验证

```sh
node --test tests/*.test.js
```

测试使用临时数据库，覆盖账号隔离、并发借阅、预约顺序、续借、到期释放、管理员权限、旧接口保护、选段校验、正文版本更新、公开回复、通知归属、举报处理、进度和私密记录。

`node scripts/preview-community.js` 在 3001 端口创建一次性临时数据库，提供仅用于本机 UI 验证的 `preview_admin` / `preview_reader`，密码 `Preview-Only-2026`；不接触正式数据库，不要作为正式服务启动。

体验方案见 [共读体验验证](docs/共读体验验证.md)。目前尚未邀请真实参与者或形成研究结论。浏览器验证截图在 `artifacts/`，含明确的测试账号和隔离测试数据。

## 已知边界

- 当前会话存储在内存中，重启需重新登录；账号和业务数据持久保存在 SQLite。可通过 `SESSION_SECRET` 配置会话密钥，未设置则每次启动随机生成。
- 暂无邮箱验证、密码找回、邮件通知、跨设备公网部署、EPUB/PDF 导入和多人实时协同编辑。
- 限额借阅目前管理阅读登记席位，不是商业电子书的授权/DRM 系统；站内公开正文不做付费内容访问控制。
- 公开回复的来源链接和依据位置由读者提供，仍需核查；帮助数不是正确性评分。
- 本机原型尚需结合真实用户反馈完善内容治理、运维和公开部署配置。
- UI 参考图素材、AI 辅助纸纹的来源记录保留在 `static/assets/README.md`。

## 复古动效

`static/motion.css` / `static/motion.js` 为按钮增加凸起底座、按下凹陷和松开回弹；窗口、标签页和目录使用短促过渡。页脚“界面动效”可试按或开启安静阅读，并遵循系统减少动态效果设置。参考来源与参数见 [动效设计](docs/动效设计.md)。
