# 棕色复古桌面的动效

2026-10-04：先检索复古界面的真实交互参考，再为现有页面编写独立的 `static/motion.css`、`static/motion.js`。不引入完整外部主题库，不改业务请求和原有布局尺寸。

## 参考及取舍

- [98.css](https://jdan.github.io/98.css/)：借鉴凸起边框、按下时转为内凹、内侧虚线焦点的交互语言。暖棕色阴影和位移参数为本项目重新实现，没有复制整个库。
- [7.css](https://7css.vercel.app/)：参考窗口与控件的连续状态变化。现有纸面界面不采用它的蓝色玻璃和高光呼吸效果。
- [MDN :active](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/:active)：用真实按下状态触发鼠标/触摸反馈，松开自动恢复。键盘 Enter/Space 使用短暂样式类补充，原有原生点击仍只触发一次。
- [MDN @starting-style](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@starting-style)：原生 dialog 的开合采用起始样式和 display/overlay 离散过渡。保留 Escape、焦点恢复与原生弹窗语义；不支持时立即开合。
- [MDN prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)：系统减少动态效果时取消位移动画；凸凹状态仍即时区分。

## 已应用

| 控件 | 表现 |
|---|---|
| 普通按钮 | 3px 暗色底座；按下 2px，内凹阴影；松开约 90ms 回弹 |
| 深棕色主按钮 | 稍深底座与内侧高光；按下后暗部收拢 |
| 窗口控制键 | 1px 按压，保持小尺寸图标清晰 |
| 标签页 | 激活项保持内凹；内容 140ms 轻微淡入 |
| 弹窗 | 150–170ms、7px 开合过渡；不做大范围缩放 |
| 目录与字号菜单 | 120ms、3px 轻微进入 |
| 图书条目 | 悬停微暖色、选中内侧描边，不移动文字排版 |
| 工作窗口 | 点击/焦点所在窗口标题栏略亮；展开恢复短暂淡入 |
| 操作提示 | 160ms、5px 淡入 |

页脚“界面动效”提供无业务副作用的试按按钮，以及“安静阅读”开关。该偏好仅保存在本机浏览器；开启后禁止自动榜单轮播，但仍可手动切换。系统减少动态效果优先，关闭安静阅读不会绕过系统设置。关闭安静阅读后，榜单可通过“继续轮播”手动恢复。

禁用按钮不发生按压或悬停抬升；未增加自动播放音效、粒子、闪烁或持续动画。按压只用独立 translate 和阴影，不改变元素尺寸或表单布局。

验证：浏览器检查原生鼠标/空格操作、按压类释放、弹窗开关、安静阅读偏好、刷新保留设置和窗口展开恢复。该修改不涉及后端或数据库。
