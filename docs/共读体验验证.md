# 下一位读者：共读体验验证

这是待执行的体验方案，不是已经完成的用户研究。浏览器和自动化测试仅验证软件行为，不能证明学习提升或环保效果。

## 目标

验证读者是否能提出具体问题、核对他人的依据，并让后来的读者用到已有讨论。首轮建议邀请 4–6 位有英文阅读需求的学生，自愿参加，每人约 20 分钟。不要在公开讨论中填写真实姓名、联系方式或其他个人隐私。

## 材料

主题馆收录一条 EPA 真实来源短引文和两篇 AI 辅助编写的原创英文练习，均有明确来源/性质标注。原创练习不等于专业原作、不作为实际维修操作指南。

EPA 来源：https://www.epa.gov/recycle/what-you-can-do ，eCycling 小节，2026-10-04 核对。站内只收录短引文，省略号表示截断，完整上下文通过来源查看。

练习关注 provided that、may、necessarily 等词对条件和论断强度的影响。不要在主持过程中提前解释答案。

## 操作流程

1. 读者 A 注册，进入“材料再利用主题馆”，选择一篇文章，记录最初理解。
2. 选中不理解的句子，打开公开讨论；或通过目录的“讨论当前段落”发起问题。明确同意公开发布。
3. 读者 B 独立阅读，通过“共读互助”发现问题，结合原文段落或核查过的来源回复。
4. 读者 A 从“消息”进入回复，打开来源核对，选择仍待解答、仍有争议或发起者已解答。允许保留不同意见。
5. 读者 C 先独立阅读，记录理解，再查看已有讨论。记录哪些解释有帮助，哪些需要进一步核查。
6. 各自在主题馆填写私密的“阅读前后记录”，写清最初理解、修正后的理解和下一步核实或行动。不会自动公开。

访谈问题：为什么选择这句？什么证据使你改变判断？是否有解释让你更困惑？哪些地方仍不能确定？你是否愿意为下一位读者补充一句解释？

## 如何解释结果

管理员统计提供公开讨论数、收到回复数、发起者标记解答数、有帮助反馈数和私密阅读记录的总数量。管理员不能从这个面板读取他人的私人记录内容。

回复率 = 至少得到一条可见回复的讨论数 / 可见讨论数。样本为零时不计算。

“有帮助”与“发起者已解答”都是主观反馈，不是准确性认证。是否理解得更准确，需要人工结合原文和上下文核对前后说明。不能从借阅量、阅读时长、点赞数直接推导知识增长或碳减排。

首轮结束后整理实际问题、截图（经参与者同意）、修改前后的设计和未解决的疑问，作为作品集证据。不要填写虚构人数、访谈或研究结论。
