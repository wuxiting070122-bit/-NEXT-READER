# 界面语言

共读工作台 `research.html` 初始使用英文。页脚 **Settings → Interface language** 可选择 English 或简体中文；选择记存在当前浏览器的 `bookloop-language` 中。不根据浏览器系统语言自动切换。

语言包源文件为 `static/locales/en.json` 与 `static/locales/zh-CN.json`。修改后运行 `node scripts/build-locales.js`，生成页面直接加载的语言包脚本。静态界面、动态按钮、弹窗、提示、通知及已知服务端错误均通过 `static/i18n.js` 本地化。

切换时刷新界面，通过一次性 sessionStorage 暂存当前账号的阅读位置、选段、过滤条件和未提交输入；恢复后即删除，超过一分钟不恢复。密码、发布同意复选框不保存；账号不一致不恢复私人输入。账号和借阅关系不受语言设置影响。

原书正文、用户批注和讨论不翻译。内置书籍的显示标题和说明有英文版本，管理员编辑时仍看到数据库原始内容，不会将翻译结果覆盖回资源。旧课程后台 `demo.htm` 和 `research-legacy.html` 保留历史页面，不属于新版工作台的语言包。

英文排版在 `static/i18n.css` 调整，保留古朴棕色、纸张纹理与机械按钮动效。英文首页手写区域使用可切换文字，中文模式保留原参考图装饰。

验证：`node --test tests/i18n.test.js`；浏览器验证英文/中文往返切换、刷新记忆、草稿保留、注册及管理弹窗、按钮键盘按压。
